Self-hosted fonts (Latin subset, variable, unmodified).

  inter-latin-wght-normal.woff2             Inter, by The Inter Project Authors (SIL Open Font License 1.1)
  plus-jakarta-sans-latin-wght-normal.woff2 Plus Jakarta Sans, by Tokotype (SIL Open Font License 1.1)

Both are the Latin-subset variable files distributed by the Fontsource project (@fontsource-variable/inter and
@fontsource-variable/plus-jakarta-sans), copied unmodified. The licences are alongside this file.
To update: install the Fontsource package, copy the new latin-wght-normal.woff2 here, and keep the file names
(they are referenced from src/styles/fonts.css and the <link rel="preload"> tags in the HTML files).
