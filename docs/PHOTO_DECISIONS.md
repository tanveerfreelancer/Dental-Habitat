# Photo decisions

Nine images were supplied. Three are used; six are deliberately not. Each decision is explained so the clinic can
overrule it. Using any of them later is a five-minute change (see the README, "Photos").

## Used

| Supplied file | Where | Why |
| --- | --- | --- |
| Interior panorama (8000 x 2571) | Hero, About, and the social-share image | Unmistakably a dental clinic: dental chair, overhead light, seating area. The blue chair echoes the site palette. One wide source gives three strong, different crops. |
| Street view of the entrance, level and clear (4128 x 2322) | Contact + Location | Helps visitors recognise the entrance. Cropped tighter so the sign and pillar sign read "Dental Habitat", and cut above the motorbike number plates and the plate naming another practitioner. |

## Not used, and why

| Supplied file | Reason |
| --- | --- |
| Second street view, tilted with a dark tree filling the frame (4128 x 2322) | The level shot of the same entrance is clearer. Straightening a tilted photo would alter it. |
| Corridor with a "Surgery-2" sign (3000 x 4000) | Genuine and usable, but hazy from lens glare, and the site must not retouch photos. The panorama crops are sharper. A good candidate if a cleaner version is taken. |
| Patient X-ray on a monitor (4000 x 3000) | A real patient's radiograph with a date stamp, photographed off a Dell screen with the Windows taskbar visible. Publishing it needs the patient's consent, and it is not a clean image. |
| Machine on a white background with the brand "MINISTAR S / SCHEU" (554 x 554) | A manufacturer's product render, not a photo of the clinic's own equipment. Using it would imply the clinic has that machine, and it relates to services (aligners, retainers, splints) that are not on the clinic's service list. |
| Intraoral scanner held in a gloved hand, blurred background (1080 x 714) | Reads as a professional or stock photo rather than the clinic's own. Using it would imply digital scanning, which is not in the clinic's service list or its Google Business Profile details. |
| Close-up of a patient's mouth wearing a wire retainer (4000 x 3000) | A close-up of an identifiable patient, needing consent, and it implies orthodontic retainer services that are not on the service list. |
| Instrument tray with an implant drill kit (399 x 599) | Only 399 pixels wide, so it would look soft at any useful size, and the implant kit implies a service (implants) that is not listed. |

If the clinic confirms that the scanner, the machine or the instrument photos are its own equipment and offers those
services, they can be added (for example as a Services header image) with alt text written from what they show.
